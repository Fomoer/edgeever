# Hacker News 剪藏

打开 `https://news.ycombinator.com/item?id=<id>` 主帖详情页，点击插件的“剪藏当前网页”，或在页面上右键选择“保存 Hacker News 主帖到 EdgeEver”。工具栏操作优先保存选中文字；专用页面右键菜单保存主帖。

笔记保留页面提供的标题、作者、原始发布时间、剪藏时的分数、外部链接和主帖正文。支持 Ask HN、Show HN 和只有链接的主帖，不包含评论。完整主帖笔记带有 `web-clip` 和 `hacker-news` 标签。

外链文章仅记录链接，不抓取其正文。缺失的元数据直接省略；评论详情页、已删除主帖和无法读取的内容会被拒绝。剪藏期间页面切换会取消保存。不增加持久网站访问权限。

正文图片沿用现有附件流程。复制失败或达到数量限制时，正文仍保留，提示会说明部分图片仍使用外部链接；并发编辑不会被覆盖。

## 验证范围

自动验证使用脱敏的公开 HN DOM 样本，包括解析器测试、实际打包的后台与注入脚本测试，以及连接本地 API 并重新打开笔记的 Chromium 插件测试。图片存储用例在 HN 样本中加入合成图片。这些检查不能替代 Chrome、Edge、Firefox 的真实网站验收或商店发布。
