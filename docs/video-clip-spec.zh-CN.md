# 视频笔记：保存网页已有字幕

用户在 YouTube 或哔哩哔哩的播放页选择「保存视频笔记到 EdgeEver」。插件读取当前页面的视频信息和平台已经提供的字幕，保存标题、作者、来源链接、可用的封面和带原片时间戳的字幕。已有字幕且工作区配置了可用的聊天模型时，可以生成总结、大纲和要点；失败不阻止笔记保存。

支持 YouTube 普通视频及 Shorts、哔哩哔哩普通视频及分 P。直播、番剧、课程和其他页面不创建视频笔记。页面没有字幕时，仅保存来源信息和「这一集没有可用字幕」，不启动语音识别。视频笔记不提供再次提取字幕的菜单，也不下载外部平台的视频或音轨。

## 笔记附件语音识别

用户可以在已上传到笔记的音频或 MP4/WebM 视频附件上主动选择「转录」。工作区配置 OpenAI 兼容语音模型和默认模型；笔记附件 API 仅接受笔记 ID 与归属该笔记的附件 ID，不接受媒体 URL。实例校验附件归属，并把当前语音模型地址、名称及凭据交给已登录客户端；凭据在实例上加密保存。Web/桌面客户端经原有资源接口分段读取附件，在本机提取音轨并按大小或时长切段，由客户端把每段不超过 24 MB 的音频直接发送到用户配置的 `/audio/transcriptions` 服务。实例只提供原有附件字节，不提取或转换音轨，也不转发模型请求。Web 浏览器中的直连要求模型服务支持跨域请求，并会使模型凭据进入当前浏览器会话；桌面端由本机主进程直接请求模型服务。识别文本先展示给用户，可复制或插入当前笔记。插件可通过 `context.ai.transcribeResource(noteId, resourceId)` 调用同一客户端能力，也可把自己的音视频 `Blob` 交给 `context.ai.transcribeMedia(blob)`；两种方法都不在返回值中提供模型凭据，也不接受媒体 URL。附件仍受普通上传上限约束；无法读取的媒体格式或音轨会明确报错。

添加服务时可用尚未保存的地址、模型 ID 和 Token 测试连接；编辑服务时可选择已添加的模型，并沿用已保存的 Token 或输入新 Token 测试。测试从当前客户端直连模型服务，发送一段内置短语音并显示返回的文本；测试不保存表单，可能产生少量模型费用。浏览器跨域限制与真实转录相同。

浏览器无法建立直连时，客户端只能报告连接未完成，不能据此判断 Token、模型或语音接口无效。服务商不允许跨域请求时，应在桌面客户端测试；不得为通过 Web 测试而改由实例转发识别请求。
“OpenAI 兼容”只说明接口形状，不能保证服务商提供 `/audio/transcriptions`；桌面端绕开浏览器跨域限制后，仍须通过真实短语音请求验证该接口及所选模型。

## 已撤回的外部媒体抓取方案：技术备忘

以下记录未上线的外部媒体抓取设计，供以后评估授权场景时参考，**不是当前产品行为或待实现需求**。撤回范围包括外部音轨抓取、浏览器登录状态复用、yt-dlp 自动安装与更新、外部视频识别任务和桌面轮询。上面的笔记附件语音识别是独立实现。

### 任务与数据边界

- 原方案把平台、视频 ID、来源 URL、时长和无字幕占位文本编码进笔记正文的隐藏标记。保存笔记本身不建任务；用户在笔记列表主动选择提取时才建任务。
- API 用工作区和笔记 ID 限定任务，记录正文内容哈希；剪藏令牌和演示实例不能创建或领取任务。条件更新只允许一个桌面端领取，约 20 分钟未完成的任务可重新领取，避免永久卡住。
- 桌面端写回同一条笔记时带修订号和内容哈希。正文被用户修改时不覆盖；原占位仍在则替换，否则追加实录。失败保留原笔记，不自动反复尝试。

### 本地媒体处理与模型调用

- 原方案按平台白名单验证 HTTPS 来源，在本机调用 yt-dlp 只选最优音轨，不保存视频；限制已知时长约 30 分钟、音频约 24 MiB、下载和识别超时。任务结束后清理临时音频。大小和时长限制只减少资源占用，不构成版权授权。
- yt-dlp 独立可执行文件从其发布页取得，并核对 SHA-256；桌面端后台检查版本。可选的 `--cookies-from-browser` 会复用本机浏览器登录状态，浏览器选择仅存在本机。这会扩大可获取的媒体范围，因此不能把「本地执行」等同于获得平台或权利人许可。
- 原方案让已登录桌面端领取语音模型凭据，并把音频直接发送到用户配置的 OpenAI 兼容 `/audio/transcriptions` 接口。当前附件转录也由客户端直连模型服务，但只处理已上传且归属当前笔记的附件；不恢复外部媒体抓取或旧任务机制。
- 模型返回分段时间戳时生成可点回原片的实录；仅返回全文时写入普通文本。任务失败记录错误码，不把 API Token 写入诊断信息。

若未来重新考虑，应先明确内容授权、平台条款、目标市场和识别服务的数据处理方式，再重新设计入口与验证范围；不能直接恢复上述抓取链路。
