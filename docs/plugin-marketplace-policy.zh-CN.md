# EdgeEver 官方插件市场上架政策

[English](plugin-marketplace-policy.md)

EdgeEver 官方插件市场仅收录自由及开源插件。本政策适用于插件进入官方市场并继续通过官方市场分发，不限制用户直接通过 GitHub 或 Manifest 地址安装其他插件。

## 开源要求

对于提交到市场的每个版本，插件开发者必须：

- 将 EdgeEver 客户端中执行的完整源码托管在公众无需账号或特别权限即可查看的公开仓库中。
- 提供 OSI 认可的开源许可证，允许使用、审查、修改和再分发。开发者负责确保所选许可证与插件包含的全部代码及依赖兼容。
- 公开人类可读且未经混淆的源码、构建配置，以及能够合理生成分发包的构建说明。只公开编译、压缩或打包后的 `main.js` 不符合要求。
- 让市场版本对应一个公开且不可变的 Git Tag 或 Commit，并确保 Manifest 和 Release 资产可以追溯到该源码版本。
- 标明打包到插件中的第三方代码，并遵守相应的许可证及源码提供要求。

在对应源码保持公开且可审查的前提下，可以分发压缩或打包后的资产。仅在独立托管服务中执行的代码无需开源，但插件详情必须明确披露对该服务的依赖、发送的数据、隐私政策及任何付费要求。

无代码主题必须公开完整 Manifest，并使用允许公众使用、审查、修改和再分发的许可证；其中包含的第三方材料也必须采用兼容条款。

## 持续上架资格

只要某个版本仍通过官方市场分发，其仓库、许可证、对应源码版本和构建信息就必须持续公开。如果插件不再满足本政策、发布资产无法追溯到声明的源码，或者其行为带来安全、隐私、法律或可靠性风险，EdgeEver 可以拒绝上架、暂停分发或下架该插件。

市场“已验证”仅表示插件在审核时通过了适用的准入与完整性检查，不代表 EdgeEver 保证插件绝对安全、没有错误或适合所有用户。
