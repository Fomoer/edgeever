# 网页区域剪藏

[English](2026-10-29-region-clip.md) · [Issue #703](https://github.com/tianma-if/edgeever/issues/703)

## 问题与目标

自动正文提取会混入无关内容。在浏览器插件中增加明确的 DOM 内容区域选择，让用户只保存所选部分。基线：`a2342067`。

## 允许变更与验收

1. 在插件弹窗现有采集入口旁增加“选择区域”。沿用点击手势内申请实例权限的机制，仅在可访问的 HTTP(S) 页面启动；配置或权限错误使用既有提示。不增加浏览器权限或常驻脚本。
2. 悬停高亮内容块，不改动来源元素；点击锁定区域，不触发网页链接或操作。提供扩大/缩小父子区域、重新选择、保存、取消。沿用 MaoXian 的键盘模型：左/右键扩大/缩小，上/下键选择相邻可见区域，锁定后 Enter 确认，保存前 Escape 退出。复用其同尺寸包裹层归一化和父子选区历史算法，保留 MIT 署名（参考 `e69fbf9c` 的 `src/js/content/ui.js`），不引入隐藏原 DOM 或保存历史选择器的系统。保留页面滚动；重复启动替换旧选择器；取消或替换清理界面和监听并恢复焦点，不创建笔记。
3. 仅明确保存时把仍存在的所选可见 DOM 转为 Markdown。复用可见性过滤及现有 HTML、表格、代码、链接和图片转换；去掉隐藏内容、脚本、表单控件及插件界面。保留网页标题、来源、采集时间及原图片本地化规则。区域为空、移除或不可读时不回退整页；不采集 iframe 内部、截图或页面之外的私有内容。
4. 复用笔记本选择、笔记创建、串行保存队列及图片流程。写入前检查内容脚本来源和网页地址未变；保存中禁用重复确认，转换或保存失败保留区域并显示错误，成功或部分图片失败复用原反馈。不自动重试；取消只适用于尚未开始保存的阶段。
5. 使用插件共享按钮、主题及 Shadow DOM 工具条，新文案同步英文、简体中文、日文、波兰文。仅增加此入口所需的注入/构建接入及双语使用文档；原整页、文字选择和平台专用采集行为不变。

验收：先加入新入口的针对性弹窗、后台及内容转换检查，再实现。真实浏览器运行构建后的选择器，覆盖选择、调整、滚动、取消、重复启动、可见内容转换、失败及保存读回；检查实际界面及所选图片沿用附件流程。执行受影响插件检查、Chromium/Firefox 构建和 Firefox lint，以及项目要求的主端/移动端类型检查和 Web 构建。使用隔离页面与存储，不操作用户笔记。

## 边界与风险

不修改 API、数据库或 migration、认证、备份、原生客户端、主应用版本号、商店发布和部署；浏览器插件版本提升至 `0.4.0`；不增加依赖。

主要风险是干扰网页操作及保存错区域。仅选择期间阻止网页激活，锁定后显示边界，写入前核对来源。回退新增弹窗/注入模块即可撤回功能；已经明确保存的笔记仍是普通笔记。Chromium、Firefox 的真实运行兼容性与构建结果分别报告。
