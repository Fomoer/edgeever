# Issue 650 桌面自动备份实施清单

[English](2026-10-23-desktop-scheduled-backup.md)

## 问题与目标

按[自动备份与加密恢复设计](../desktop-scheduled-backup-design.zh-CN.md)实现 [Issue #650](https://github.com/tianma-if/edgeever/issues/650)。桌面端把当前账号已同步的知识库写入用户选择的本地目录，可用独立密码加密，并能在原实例不可用时恢复到新实例。

影响桌面后台、共享归档、设置与恢复入口、备份读取 API 和新增 migration。版本触发器影响正常写入、归档不可恢复、明文泄漏和误删备份是主要风险。关闭功能停止新任务并保留文件；数据库回滚保留新增结构，触发器问题使用后续 migration 修复。真实旧库升级、跨平台目录与凭据、恢复流程需分别验收。

附件恢复接口返回 503 时，归档消费回调的异常被统一改成 `invalidZip`，随后桌面 IPC 丢失 HTTP 状态，误导用户认为备份损坏。修正异常归属并通过既有桌面日志保留失败接口的诊断信息；主要风险是错误分类回归或日志泄露敏感字段。仅读取 ZIP 的异常继续报坏包，日志采用限定字段和现有脱敏；回滚本项恢复原错误链路，不修改归档和恢复数据。

本地 Wrangler 4.112.0 的空 Worker 在固定 5 秒请求间隔下也返回 503；该版本开发代理存在空闲连接竞争及错误来源误判。通过仓库已有的 Bun 依赖补丁修正本地开发转发，不给恢复写请求增加重试。风险是本地代理兼容性回归；补丁限定在本地 HTTP 转发，保留远程与 WebSocket 行为，撤回补丁及其包/锁文件登记即可回滚。当前正在运行的服务保持不变，真实业务恢复需用户重启开发服务后验收。

桌面旧导出与自动备份入口重复，历史文件不能直接恢复或删除，未变化的数据仍生成重复包。本次统一“备份与恢复”，保留手动明文/加密选择，并把检查结果与实际文件生成时间分开。风险集中在命名冲突、文件所有权及跳过条件；所有文件操作绑定当前备份集，跳过只依据已有修订协议与可用的上次文件。回滚界面和新增字段不迁移或改名旧包；使用隔离目录验证，现有实例、进程和用户文件不做操作。

展开备份设置时，内容区新增纵向滚动条，使卡片缩窄并重新换行；设置位于历史列表末尾也不易发现。将折叠设置移到状态区下方、历史列表上方，并让设置页的宽屏与窄屏滚动区固定预留滚动条空间。风险仅限留白和窄窗口布局；撤回这两处布局调整即可回滚，不改变默认折叠、配置、备份或恢复行为。需检查实际展开/收起宽度、键盘操作和窄窗口显示。

贡献分支以当前官方 main 为基线，只移植本功能，不带入部署 Fork 快照历史。新增备份 migration 使用未占用的递增编号，保留上游所有已发布 migration、笔记本外观字段和语言目录。集成风险是迁移顺序、归档字段或原调用方回归；在隔离旧库升级和新旧导出/恢复流程中验证，回滚代码不删除已有数据或迁移结构。现有开发工作区和用户实例保持不变。审查覆盖 B01–B19 的功能正确性、必要复杂度和实际界面；仅修复有证据的问题，具体行为修正先逐项加入清单。

## 允许的行为与验收

| 编号 | 行为变化 | 验收方式 |

| B01 | 新增递增 migration：工作区 `backup_revision` 默认 0；笔记本、笔记、正文、修订、资源和提示词插入、更新、删除在原事务内推进所属工作区版本，关系移动覆盖两侧，删除前解析归属。API 用十进制字符串传输版本，不改变同步游标。 | 真实旧 migration 数据升级后编辑、同步、删除与恢复；覆盖各实体、批量操作和工作区隔离。 |
| B02 | 新增 `/api/v1/backups/state`、`/api/v1/backups/data`：当前会话决定工作区，沿用原备份访问权限；状态包含协议、身份、版本和计数，数据按稳定 ID 游标分页。页前后和附件完成后版本不符返回 `backup_source_changed`；禁止缓存和滞后副本读。旧服务端不支持时新自动备份提示升级，不弱化导出。 | 实际路由、数据库和资源读取，验证并发增删改、身份变化、权限、游标完整性、旧接口可用。 |
| B03 | 新桌面备份只读取当前账号已同步的未删除笔记、笔记本、标签和状态、修订、提示词与有效附件；不主动同步，不读缓存兜底，不含回收站、凭据、部署/分享/表单配置及未登记外部文件。附件校验长度与已有摘要，缺摘要时读取中生成，缺失或不符失败。 | 同一组数据导出后在新实例恢复，核对范围和附件；断网及缺资源时不成功、不清理旧包。 |
| B04 | 共享归档沿用 `edgeever-zip` v2 结构，保留 ZIP v1/v2 和可空摘要；通过锁定版本的 `@zip.js/zip.js` 补齐 ZIP64，保留许可证，不替换无关压缩。新桌面和大包流式读写及背压，原 Web 手动导出的 128 MiB 缓冲路径和既有单文件限制不变。 | 原备份测试及普通/ZIP64 往返；实际大于 4 GiB 的文件流和 ZIP64 条目数边界；定向内存观察。 |
| B05 | `.edgeever.enc` 使用设计的 40 字节 EDGB v1 头、AES-256-GCM、PBKDF2-HMAC-SHA256 600000 次、32 字节密钥、随机 16 字节 salt/12 字节 IV/16 字节 tag，文件头为 AAD。仅接受设计套件，密码 UTF-8 不裁剪；ZIP 输入上限 `2^36 - 32` 字节，超出中止并保留旧包。 | 容器互通、错误密码、头/密文篡改、截断、未知参数和长度边界；认证失败无恢复写入。 |
| B06 | 主进程持有实例/账号绑定的安全凭据，不向服务端、普通配置、localStorage、日志或备份目录写密码，不向设置页回显。Linux basic_text 或安全存储不可用/锁定时暂停加密自动任务，允许只输入一次密码执行、不保存；不得明文降级。新密码只用于新包。 | 安全存储适配和真实平台检查；跨设备密码恢复；失败与密码修改行为。 |
| B07 | 主进程调度、独立后台任务执行、受限 IPC；不依赖渲染器。首次自动关闭、加密关闭，每周频率、5 份；频率每天/每周/两周/月，保留 3/5/10/20。主进程启动时通过已保存会话恢复账号，不以渲染器 IPC 为前提；启动、登录就绪、唤醒及每小时检查，首次开启到期，错过周期补一次；本机日历计算并在时区变化后重算。 | 生命周期、日历月底、首次启用和既有成功记录；设置页关闭、渲染器重载、托盘和唤醒流程。 |
| B08 | 手动与自动共用互斥、配置和校验，关闭自动仍可立即备份；运行中先取消再改设置。失败不推进成功时间，网络/版本失败自动最早一小时后重试、手动可立即重试；需要用户处理的错误显示操作，不反复弹窗。完整退出取消任务。自动触发在取得互斥后复查开关、到期和退避；任务结束取消未完成请求并释放 worker。 | 并发触发、取消、失败后重试、退出再启动；前台编辑可用。 |
| B09 | 配置、任务上下文和记录按实例/账号隔离，本机随机 backupSetId；切换或登出取消，上下文过渡期间不接受旧账号操作，迟到响应不得发布/记成功/清理。根目录默认系统 Documents/EdgeEver Backups，原生选择目录后使用备份集子目录，自动任务文件名 UTC+随机 ID，手动命名见 B15。 | 实际账号/实例切换和目录选择，迟到响应及其他设备/账号文件保护。 |
| B10 | 同目录唯一 `.part` 流写、完成校验并刷新后原子发布、持久化完成记录，再保留最近 N 份并通知。发布前失败删除本任务临时文件，不清理旧包；中断完成记录须核对恢复；加密中断包可用其原密码单次核验，不替换当前保存密码。只删当前备份集已完成记录中的文件，不跟随符号链接、不按 mtime 推断；清理失败为独立警告。改目录/关闭/新安装不删除旧文件；只显示本地完成。 | 磁盘/权限/中断/取消/清理失败，发布恢复、保留和所有权；明文不进入同步目录。 |
| B11 | 桌面数据备份卡片含目录、频率、份数、加密及密码确认、运行/取消、打开文件夹、上次成功/下次时间/错误；历史列表与手动入口按 B15–B18 展示；存在未核验中断包时显示核验操作。密码非空且确认完全相同，保存只显示已设置；提示已同步范围及改密码只影响新包。复用现有 UI 和 Tooltip，配齐现有语言目录。 | 真实设置与备份交互、键盘、状态和失败提示，实际截图检查。 |
| B12 | 桌面原导入入口按头识别 ZIP/加密包；文件选择器默认打开当前设置的实际备份目录（含备份集子目录），仍可选择其他目录的文件，不创建目录或增加来源限制。解锁密码框使用表单提交，按 Enter 等同点击“解锁并检查”；密码为空或正在处理时不提交。解锁窗口保留到解密和归档检查通过；失败在密码框内提示并允许重试，检查期间显示进度、禁用密码编辑和重复提交，取消会终止本次检查并关闭窗口。导入错误与暂存清理警告独立于自动备份状态，不清除或覆盖其错误、警告及成功记录；旧记录中没有待核验发布包的 `backup_decrypt_failed` 归入导入错误，待核验发布包的同名错误仍归备份。先在私有目录完整认证解密，再扫描格式、路径、CRC、数量、关系和附件；目标账号/实例/计数确认后才恢复。保持同 ID 覆盖、无关数据保留、分批失败可重试和全部成功后刷新。Unix 暂存目录0700/文件0600、Windows用户私有ACL；成功/失败/取消清理自建明文，崩溃仅清理已登记暂存；旧暂存或 part 清理失败时保留登记，在清理成功前不覆盖为新任务。 | 断开原实例后普通和加密恢复至新实例；取消、坏包零写入、部分恢复重试、暂存清理和原 ZIP 兼容；校验文件选择器收到当前实际备份目录，且仍接受其他目录的原生选择；实际浏览器验证 Enter 与点击传入同一解锁参数、空密码和处理中不会提交、取消不会触发解锁；真实浏览器验证错误密码留框、重试通过后确认、检查中取消、普通坏包与恢复错误的归属；主进程测试验证导入失败/成功/清理警告不覆盖备份状态及旧记录归属。 |
| B13 | ZIP 读取、解压和 CRC 异常仍归为 `invalidZip`；条目消费回调及目标恢复异常保留原始错误，不再伪装为坏包。桌面 IPC/状态保留 HTTP 状态码及服务端错误码、消息，界面在真实错误旁显示 HTTP 状态。桌面备份/恢复的 HTTP 失败写入既有 `desktop.log`，含时间、任务类型/阶段、方法、去掉查询串的接口路径、HTTP 状态和服务端错误码/脱敏消息；非 JSON 错误使用 HTTP 状态说明，不记录请求头、请求正文、原始响应体、密码、令牌或笔记内容。日志失败不改变任务结果。附件上传初始化仅在消费首个数据块或关闭空条目时启动并立即等待；快速失败走正常恢复错误链路，不得因未处理拒绝终止 Node worker。保持现有取消、恢复分批、已有重试规则及账号隔离，不新增重试或 fallback，不修改文件名。 | 先复现消费回调错误被改成坏包；受控真实 worker 在第三个附件初始化返回 JSON/非 JSON 503 时保留状态和消息，前两份成功、第三份不上传、暂存清理；主进程验证日志限定字段、脱敏、日志异常不干扰任务及错误状态；浏览器显示 HTTP 503 而非坏包，已有 CRC 坏包检查仍通过。真实 Node 回归结合异步归档读取与立即失败的上传初始化，确认没有未处理拒绝且原状态码、错误码和消息完整保留。 |
| B14 | 使用已有 Bun 补丁机制，固定当前官方 Wrangler CLI 4.112.0，开发代理到回环地址的普通 HTTP 转发通过既有 Miniflare service binding 使用 Wrangler 已捆绑的 Undici，设置 pipelining=0，每次使用新连接，避开约 5 秒空闲关闭竞争；远程目标、HTTPS、Upgrade/WebSocket 保持原生转发。将当前 Miniflare 本地 loopback 服务的 keepAliveTimeout 和 headersTimeout 设为 0，避免进入 Node 适配器前的同类竞争；loopback 写响应遵守下游背压，下游关闭时停止读取上游流；随 Wrangler 固定其当前传递版本 4.20260714.0。回补上游 PR #14593 的 origin 比较，使未更换 Worker 时的连接错误直接上报而非伪装成重启 503 或挂起 GET；真实 Worker 更换时保留现有排队/503 行为。不增加任何恢复 POST 自动重试或其他 fallback，不重启现有服务，不修改业务数据、部署命令、版本号、归档和文件名。 | 先用空 Worker 复现当前代理 503，修正后在相同 5 秒间隔与隔离实例验证；针对实际安装的代理测试回环 HTTP 连接、WebSocket/远程保持、同源连接错误与真实更换 Worker 的行为，以及非幂等请求不重试；运行已有 Wrangler 启动器检查，将漏计新增备份 migration 的触发器数量从 12 更新为 30，保留逐条单行格式断言。确认冻结锁文件安装能自动应用补丁。 |

## 保持不变的边界

- 不修改旧 migration、同步协议、笔记 ID 与权限规则。旧 `/backups/json`、Web 手动普通 ZIP、浏览器受限缓冲导出及本地 SQLite 恢复保持原使用条件。
- 不实现 WebDAV/S3 直传、退出应用后的系统服务、Web 加密入口、移动端原生入口或整实例镜像；不改安装器、自动升级、版本号及发布流程。
- 不操作已有用户实例、生产数据库、已安装桌面应用或用户网盘内容。验证使用隔离目录与测试实例；仅提交、推送贡献分支并创建 PR，不发布或部署。
- 仅增加实现上述能力必需的共享组件、依赖、构建包含项、fixture 和测试适配。沿用 Cloudflare/Docker 共用业务逻辑。
