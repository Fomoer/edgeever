# “插入公式”支持化学式与化学方程式

[English](2026-10-28-chemistry-formulas.md)

## 问题与结果

实现 [Issue #717](https://github.com/tianma-if/edgeever/issues/717)。此前化学式只能手动用上下标、箭头命令和 `\mathrm{}` 拼写。笔记中的公式现在支持 KaTeX 的 `mhchem` 扩展：`\ce{…}` 用于化学式和化学方程式，`\pu{…}` 用于带单位的物理量。“插入公式”对话框新增“数学 / 化学”切换，并提供一键示例。

## 行为

| ID | 行为 | 验收 |
| --- | --- | --- |
| C01 | 共享公式扩展注册 `katex/contrib/mhchem`，因此 `\ce` 和 `\pu` 可在 Web 与桌面编辑器、Android 与 iOS 编辑器、公开分享页和笔记本站点中渲染。对话框预览和公众号复制同样注册该扩展。`trust: false` 仍然生效，`\ce` 中的 `\href` 等命令只作为无效文本显示。 | 共享测试仅通过共享模块渲染所有示例（行内与独立公式），移除注册后测试失败。 |
| C02 | 公式按原样保存为行内或独立公式（`$\ce{H2O}$`、`$$…$$`），没有数据、API 或迁移变化。 | Markdown 往返测试。 |
| C03 | 新建和编辑公式时都显示“数学 / 化学”切换。化学模式使用 LaTeX 源码输入，因为可视化数学编辑器会改写 `\ce`；包含 `\ce` 或 `\pu` 的公式会以该模式打开，源码中包含它们时隐藏可视化编辑器切换。 | 浏览器测试：插入、编辑并重新打开行内和独立化学公式。 |
| C04 | 十个示例（化学式、离子、反应、平衡、反应条件、气体/沉淀、物态、同位素、结晶水合物、单位）插入到光标处；光标位于未闭合的 `\ce{…}` 中时只插入示例内容。每个示例都有显示源码的 Tooltip。所有已发布语言均有文案。 | 插入逻辑与文案的单元测试；`pl-PL` 下 1280 px 和 390 px 的浏览器测试。 |

## 风险与回滚

编辑器包增加 mhchem 模块（压缩后约 34 KB）。旧版本应用在更新前会把已有的 `\ce` 公式显示为渲染错误，保存的文本不变。仓库中提交的 iOS 编辑器包（`apps/ios/EditorBundle`）需要在常规 iOS 发布步骤中重新构建才会包含该扩展。回滚即 revert；回滚后已保存的化学公式会重新显示为渲染错误。
